# Milestone 4 – Warehouse Efficiency Dashboard

## Overview
The Warehouse Efficiency Dashboard provides insights into warehouse performance by analyzing utilization, stock levels, order volume, and sales. It helps identify highly utilized warehouses, capacity risks, and overall operational efficiency.

## Dashboard Features

### KPI Cards
- Total Warehouses
- Maximum Utilization %
- Minimum Utilization %
- Average Utilization %

### Visualizations
- Warehouse Utilization (%) by Warehouse
- Warehouse Units Sold by Warehouse
- Warehouse Capacity vs Stock (Bubble Chart)
- Utilization Share by Warehouse (Pie Chart)
- Warehouse Performance Table
  - Warehouse Name
  - Total Orders
  - Units Sold
  - Total Sales
  - Units per Order

### Filters
- Warehouse Name
- Capacity Risk Flag
- Category Name

## Key Insights
- Compare utilization across all warehouses.
- Monitor warehouse capacity against stock quantity.
- Identify warehouses with higher sales and order volume.
- Detect warehouses with high capacity utilization.
- Analyze warehouse contribution using utilization share.

## Technologies Used
- Microsoft Power BI
- DAX
- Star Schema Data Model
