# Milestone 3 – Power BI Dashboard Development

## Objective
The objective of Milestone 3 is to develop interactive Power BI dashboards for supply chain analysis and visualize important performance indicators.

## Dashboards Developed

### 1. Supplier Performance
This dashboard analyzes supplier performance using key metrics such as:
- Total Suppliers
- Average Supplier Quality
- Average Supplier Reliability
- Average Lead Time
- Purchase Order Fulfillment
- Supplier Quality vs Reliability
- Top Suppliers by Reliability
- Supplier Scorecard

### 2. Transportation Analytics
This dashboard analyzes transportation and delivery performance using:
- Total Orders
- On-Time Delivery %
- Late Delivery %
- Average Shipping Time
- Orders by Market
- Orders by Shipping Mode
- Late Delivery % by Market
- Average Profit per Order by Shipping Mode
- Shipping Mode Performance

## Tools Used
- Microsoft Power BI
- Power Query
- DAX
- GitHub

## Files
- `Milestone3_PowerBI.pbix` – Power BI dashboard file
- `Screenshot/` – Screenshots of the developed dashboards

## Outcome
The dashboards provide visual insights into supplier reliability, supplier quality, transportation performance, shipping modes, delivery delays, and overall supply chain performance.
